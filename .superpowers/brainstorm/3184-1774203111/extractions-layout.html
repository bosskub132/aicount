A. Side Panel Expands

Click "Edit" in side panel → it expands to full-width overlay with document image + all editable fields. "Back" collapses. Never leaves the Documents page.

Pros

  • Never lose document list context
  • Smooth expand/collapse transition
  • Single page for everything

Cons

  • Complex panel state management
  • URL doesn't change (no deep linking to edit)

B. Keep Separate Extractions Page

Side panel shows read-only preview. "Edit Details" navigates to full Extractions page with breadcrumb back. Dedicated URL per document.

Pros

  • Full screen space for complex editing
  • Deep-linkable URL per document
  • Clean separation of concerns
  • Room for line items + journal entries

Cons

  • Page navigation (context switch)
  • Two pages to maintain

C. Everything in Side Panel

Remove Extractions page entirely. All fields, line items, and journal entries editable in the side panel with collapsible sections.

Pros

  • One page for everything
  • No navigation at all

Cons

  • Cramped for line items & journals
  • No document image preview space
  • Scroll fatigue with many fields
  • Bad UX for complex edits
